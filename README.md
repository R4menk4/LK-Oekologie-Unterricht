# LK-Oekologie-Unterricht

Sechs Lernprogramme für den Biologie-Leistungskurs Q2 mit gemeinsamer Kachelübersicht.

- Lotka-Volterra
- Artbeziehungen
- Nahrungsnetz
- Kohlenstoffkreislauf
- Permafrost
- Fachbegriff-Trainer Populationsdynamik

Die Programme laufen auch offline: gesamten Ordner herunterladen, entpacken und index.html öffnen. Ergebnisse vor dem Schließen über die Funktionen des jeweiligen Programms sichern.

Artbeziehungen: https://github.com/R4menk4/Q2-Oekologie-Artbeziehungen
